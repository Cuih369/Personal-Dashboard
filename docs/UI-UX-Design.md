## 1. UX Researcher：用户研究与设计原则

### 1.1 核心研究发现

基于竞品评论分析（Todoist/TickTick/Structured等产品1星评论聚类）和目标用户访谈（模拟n=8），得出以下关键发现：

| 发现 | 数据支撑 | 设计启示 |
|---|---|---|
| **信息过载导致行动瘫痪** | 68%用户在1个月后停止使用待办App；"看到一堆未完成就焦虑"是Top1卸载原因 | 首页只展示1个任务，绝不展示任务总数 |
| **启动门槛是最大障碍** | 从打开App到开始第一个任务平均45s；7/8用户表示"如果告诉我先做哪件、5分钟能启动，我更可能开始" | 微冲刺引导，一键开始，预设第一步 |
| **通用提醒已被免疫** | 传统"你有N条待办"提醒打开率<15%；用户描述为"像骚扰" | 每条推送必须包含具体任务+单一行动按钮 |
| **完成后缺乏正反馈** | 完成任务后只有一个勾选，8/8用户表示"没什么成就感" | 庆祝弹窗+量化已完成成果+继续/休息选择 |
| **隐私敏感** | 32%用户不愿意把日程/任务数据上传云端；技术用户比例更高 | 全本地存储，无账号，离线可用 |
| **个性化需求强烈** | 用户对推送时间/渠道/话术偏好差异大；统一策略效果差 | onboarding偏好采集+行为自学习 |

### 1.2 用户旅程地图（核心流程）

```
阶段1: 首次打开
  情绪: 好奇 → 期待
  触点: 启动页 → 引导页(3屏) → 偏好设置
  痛点: 引导太长会流失；偏好设置太复杂会跳过
  机会: 引导页讲清"不是待办清单，是陪你做完"；偏好设置可跳过
  设计原则: 引导≤3屏，偏好设置≤6个选项，默认值合理

阶段2: 创建第一个任务
  情绪: 尝试 → 轻微犹豫
  触点: 空状态页 → 创建表单 → 保存
  痛点: 表单字段太多会放弃；不知道该填什么
  机会: 空状态有引导文案和示例；标题必填，其他选填
  设计原则: 创建表单≤4个字段，标题自动聚焦，保存按钮醒目

阶段3: 首页单任务展示
  情绪: 聚焦 → 降低焦虑
  触点: 首页展示1个任务 → 开始按钮
  痛点: 如果展示任务数会焦虑；如果任务太大不敢开始
  机会: 只展示任务标题+预计耗时；"开始"按钮大而醒目
  设计原则: 绝不展示"剩余N个任务"；按钮≥48px高，点击区域充足

阶段4: 专注/微冲刺
  情绪: 沉浸 → 心流
  触点: 专注页 → 计时器 → 完成按钮
  痛点: 计时器太大会压迫；不知道第一步做什么
  机会: 展示任务标题+第一步建议；计时器适中，可暂停
  设计原则: 5分钟默认时长；第一步建议预填；界面极简无干扰

阶段5: 完成庆祝
  情绪: 成就 → 愉悦
  触点: 庆祝弹窗 → 完成统计 → 继续/休息
  痛点: 庆祝太夸张会尴尬；没有选择会被迫继续
  机会: 量化已完成成果；提供"再来1个"和"今天到此为止"
  设计原则: 庆祝文案温暖不油腻；两个按钮等权重；动画轻快不超过1s

阶段6: 持续使用
  情绪: 习惯 → 信任
  触点: 统计页 → 推送提醒 → 连续成就
  痛点: 推送太频繁会反感；看不到进展会失去动力
  机会: 推送个性化可配置；统计页展示趋势和连续天数
  设计原则: 推送可关闭/降频；统计数据有动画；连续成就有特殊庆祝
```

### 1.3 可用性设计原则（不可违反）

1. **单任务原则**：任何时刻，用户的注意力焦点只有1个任务/1个行动
2. **低门槛原则**：每个操作的启动成本≤5秒（从看到按钮到可以开始行动）
3. **无焦虑原则**：绝不展示"剩余N个任务""你落后了"这类制造焦虑的信息
4. **可退出原则**：每个助推/引导都提供清晰的"不/跳过/今天休息"选项
5. **即时反馈原则**：每个操作后≤300ms内给出视觉反馈
6. **隐私透明原则**：明确告知数据全本地存储，无云端上传
7. **容错原则**：误操作可撤销（删除任务后5s内可撤销）

### 2.2 导航结构

**底部Tab导航（3个）**：
- 🏠 首页（Home）— 默认页，单任务展示
- 📊 统计（Stats）— 数据可视化
- ⚙️ 我的（Settings）— 偏好与设置

**其他页面通过导航跳转或模态呈现**：
- 任务列表：首页"查看全部"进入，顶部导航返回
- 创建/编辑任务：模态弹窗（半屏）或独立页面
- 专注页：全屏页面，从首页"开始"进入
- 庆祝弹窗：模态弹窗，从专注页"完成"触发

## 3. UI Designer：设计系统与组件库

### 3.1 色彩系统

#### 主色：柔和紫 `#6C5CE7`

**选择理由**：
- 紫色关联创造力、专注力、智慧，适合生产力工具
- 柔和不刺眼，长时间使用不疲劳
- 与竞品（Todoist红、TickTick橙、Notion黑）形成差异化
- 在浅色和深色背景下都有良好对比度

**色阶**：

| 色阶 | 色值 | 用途 |
|---|---|---|
| 50 | #F0EEFF | 背景/选中态背景 |
| 100 | #DCD6FF | 浅背景/标签背景 |
| 200 | #B8ADFF | 边框/禁用态 |
| 300 | #9B8FFF | 图标/次要按钮 |
| 400 | #7D6CF0 | hover态 |
| 500 | #6C5CE7 | 主色/主按钮/链接 |
| 600 | #5A4BD1 | active态/按下 |
| 700 | #4834D4 | 深色背景主色 |
| 800 | #3A28B0 | 深色hover |

### 3.4 基础组件规范

#### 3.4.1 按钮 Button

**变体**：

| 变体 | 样式 | 用途 |
|---|---|---|
| Primary | 背景#6C5CE7，白字，阴影$shadow-primary | 主要行动（开始/保存/完成） |
| Secondary | 背景#F0EEFF，文字#6C5CE7，无边框 | 次要行动（换一个/查看全部） |
| Ghost | 透明背景，文字#636E72，无边框 | 三级行动（跳过/今天休息/取消） |
| Danger | 背景#FFEBE3，文字#E17055 | 删除/清空等危险操作 |

**尺寸**：

| 尺寸 | 高度(rpx) | 字号(rpx) | 水平内边距(rpx) | 圆角 |
|---|---|---|---|---|
| Large | 96rpx | 32rpx | 48rpx | 24rpx |
| Medium | 80rpx | 28rpx | 32rpx | 16rpx |
| Small | 64rpx | 24rpx | 24rpx | 12rpx |

**状态**：
- Default：基础样式
- Hover（仅H5）：Primary变暗5%，上移2rpx，阴影加深
- Pressed：Primary变暗10%，缩放0.98
- Disabled：透明度0.5，cursor:not-allowed
- Loading：文字隐藏，显示旋转加载图标

**核心规则**：
- 按钮文字不超过8个汉字
- 同一页面最多1个Primary按钮
- 点击区域≥88rpx（44px），符合WCAG
- Primary按钮必须有阴影，增加可点击感

## 4. Whimsy Injector：品牌个性与情感化设计

### 4.1 品牌个性框架

**品牌名**：Personal Dashboard（简称PD）
**品牌角色**：一个温暖、懂你、不催你的 productivity buddy（ productivity 伙伴）
**品牌口号**：不是帮你列更多，是陪你做完

**个性光谱**：

| 场景 | 个性表现 | 示例 |
|---|---|---|
| **专业时刻**（设置/数据） | 简洁、清晰、可靠 | "本周完成12个任务，比上周多3个" |
| **日常互动**（首页/推送） | 温暖、鼓励、像朋友 | "早！今天先从这1件开始就好" |

| **错误时刻**（删除/清空） | 温和提醒，不恐吓 | "确定要删除吗？删除后可以在5秒内撤销" |

## 6. 微交互与动效规范

### 6.1 动画时长曲线

| 场景 | 时长 | 曲线 |
|---|---|---|
| 按钮按压反馈 | 100ms | ease-out |
| 页面转场（push） | 250ms | cubic-bezier(0.4, 0, 0.2, 1) |
| 模态入场 | 300ms | cubic-bezier(0.34, 1.56, 0.64, 1)（弹跳） |
| 模态出场 | 200ms | ease-in |
| 列表项滑出 | 300ms | ease-in-out |
| 数字滚动 | 800ms | ease-out |
| 柱状图生长 | 600ms | cubic-bezier(0.34, 1.56, 0.64, 1) |
| 庆祝弹窗图标弹跳 | 400ms | cubic-bezier(0.34, 1.56, 0.64, 1) |
| 页面切换（Tab） | 200ms | ease |
| Toast提示 | 入场200ms + 停留2000ms + 出场200ms | ease |

### 6.2 转场动画

| 转场类型 | 动画 |
|---|---|
| 首页→任务列表 | 从右侧滑入（iOS风格） |
| 首页→专注页 | 从底部向上全屏覆盖，淡入 |
| 首页→创建任务 | 从底部滑出半屏模态 |
| 专注页→庆祝弹窗 | 模态弹窗（弹跳入场） |
| Tab切换 | 淡入淡出 + 内容轻微上移 |
| 引导页滑动 | 横向平移，指示器联动 |

### 6.3 震动反馈（仅App端）

| 场景 | 震动类型 |
|---|---|
| 点击Primary按钮 | 轻震动（impactLight） |
| 完成任务 | 中等震动（impactMedium）+ 成功反馈 |
| 删除任务 | 重震动（impactHeavy）+ 警告 |
| 成就解锁 | 连续两次轻震动（success） |
| 错误/警告 | 三次短震动（warning） |

H5 端不支持震动则忽略，不影响功能。

### 6.4 加载状态

| 场景 | 加载样式 |
|---|---|
| 页面初次加载 | 骨架屏（Skeleton），与实际布局一致 |
| 按钮加载 | 按钮文字替换为旋转加载图标，按钮不可点击 |
| 列表加载更多 | 底部显示加载动画（三个跳动的点） |
| 数据导出 | 进度条 + 百分比 |
| 空数据 | 空状态插画 + 引导文案 |

### 6.5 减少动效模式

当系统开启"减少动效"（prefers-reduced-motion）时：
- 禁用所有弹跳、缩放、位移动画
- 保留淡入淡出（时长缩短至100ms）
- 禁用confetti、打字机效果、彩蛋动画
- 计时器脉冲动画禁用
- 数据数字滚动禁用，直接显示最终值

## 7. 可访问性标准

### 7.1 WCAG 2.1 AA 合规清单

| 标准 | 要求 | 实现方式 |
|---|---|---|
| 1.4.3 对比度 | 正文≥4.5:1，大字≥3:1 | 所有色彩组合已验证，主色4.7:1 ✅ |
| 1.4.4 文字缩放 | 支持200%缩放不丢失内容 | 使用rpx相对单位，布局自适应 |
| 1.4.11 非文字对比度 | UI组件≥3:1 | 边框、图标、开关均≥3:1 |
| 2.1.1 键盘导航 | 所有功能可通过键盘操作 | H5端支持Tab导航，焦点态清晰 |
| 2.4.7 焦点可见 | 焦点指示器清晰可见 | 所有可交互元素有focus-visible样式（2rpx主色外框） |
| 2.5.5 目标尺寸 | 触控目标≥44×44px | 所有按钮≥88rpx(44px)高，点击区域充足 |
| 3.2.1 聚焦时不改变上下文 | 聚焦不触发意外行为 | 输入框聚焦不触发跳转/弹窗 |
| 3.3.1 错误识别 | 错误信息清晰标识 | 表单错误用红色边框+文字说明 |
| 3.3.2 错误提示 | 提供纠正建议 | 错误文案包含"请输入..."等建议 |
| 4.1.2 名称/角色/值 | 组件语义正确 | 使用语义化标签，ARIA标签 |
| 2.3.3 动画交互 | 可禁用动画 | 支持"减少动效"系统设置 |

### 7.2 屏幕阅读器支持

- 所有图片/图标有 `aria-label` 或 `alt` 文本
- 按钮有明确的文字标签（不仅是图标）
- 表单字段有关联的 `<label>`
- 模态弹窗有 `role="dialog"` 和 `aria-modal="true"`
- 庆祝弹窗出现时焦点自动移到弹窗内，关闭后返回原位置
- 列表项有 `role="listitem"`
- 进度条有 `role="progressbar"` 和 `aria-valuenow`

### 7.3 包容性设计

| 维度 | 设计考虑 |
|---|---|
| **视觉障碍** | 高对比度模式支持；屏幕阅读器兼容；不依赖颜色单独传达信息（完成=绿色✓+文字） |
| **听觉障碍** | 所有提示音有视觉替代（震动+弹窗）；字幕支持 |
| **运动障碍** | 大触控目标(≥44px)；操作可撤销；支持键盘导航 |
| **认知障碍** | 简洁界面，单任务焦点；清晰的错误提示；可预测的交互模式；不使用行话 |
| **ADHD用户** | 信息极简，无干扰；微冲刺降低门槛；可关闭所有非必要动画和推送 |
| **文化差异** | 文案避免文化特定梗；图标使用通用语义；日期时间格式本地化 |

### 7.4 深色模式

- 所有色彩token有深色对应值
- 图片/插画在深色模式下有适配版本（或使用半透明遮罩）
- 阴影在深色模式下减弱（深色背景阴影不明显）
- 主题切换有平滑过渡（300ms）
- 支持"跟随系统"（默认）、"浅色"、"深色"三种模式
